Property Type Default Description

Toast Service

Display fast, non-blocking toast overlay notifications anywhere on the screen using a clean service provider.

Interactive Playground

Success Toast Info Toast Warning Toast Danger Toast
Custom Notification Builder:
Trigger Notification

Inject the service BaseToastService in your component and call its reactive display methods. To render toasts, add <base-toast-container></base-toast-container> inside the root page component (e.g. app.html).

Component Injection Snippet 
// 1. In your component TypeScript code:
import { BaseToastService } from '@base/ui';
// ...
constructor(private toast: BaseToastService) {}

triggerNotification() {
  this.toast.success('Validation block synced successfully.');
}

// 2. In your main root template app.html:
<base-toast-container></base-toast-container>
